# The Filing Desk

Plain-language reports on US-listed companies' results, built from their SEC filings.

Live site: https://jonmc19.github.io/The-Filing-Desk/

## How it's organised

- `src/assets/`: shared styles, chart helpers and self-hosted fonts (SIL Open Font License)
- `src/reports/<slug>/`: one folder per report, with `meta.json`, `body.html`, `data.json` and `charts.js`
- `build.py`: builds the site into `docs/`, which GitHub Pages serves

## Add a report

1. Create `src/reports/<slug>/` with the four files (copy an existing report as a template).
2. Run `python3 build.py`.
3. Commit and push. The home page, sitemap and figures CSV are regenerated by the build.
